# Pulse — Modern Social & Room Chat Web App

Pulse is a lightning-fast, production-ready single-page social web app built with **Tailwind CSS** and **Vanilla JavaScript**, self-contained in a single `index.html` file for instant deployment on **Vercel**.

## Features

- **Dark Slate UI**: Crafted with a gorgeous dark slate color palette (`slate-950`, `slate-900`, `slate-850`) and neon indigo/violet accents.
- **Community Feed**: Interactive post stream with real-time like counters, comments, image attachments, and tag filtering (`#tech`, `#design`, `#ai`, `#career`, `#random`).
- **Instant Chat Rooms**: Multiple live discussion rooms with real-time message streams, live online user counters, file/image attachment simulation, and simulated peer replies.
- **Trending Topics & Contributors**: Leaderboards and curated hashtags capturing community buzz.
- **Responsive Design**: Fully optimized for mobile screens with slide-out navigation drawers and adaptive desktop sidebars.
- **Zero Build Steps**: Pure HTML5, Tailwind CSS via CDN, and FontAwesome icons. Ready for immediate Vercel deployment.

## Instant Vercel Deployment

1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Keep default settings (no build command needed).
4. Deploy instantly!
